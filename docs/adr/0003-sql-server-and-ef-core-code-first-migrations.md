# ADR-0003: SQL Server and EF Core code-first migrations

Status: Accepted (4 November 2026)

## Context

A relational store fits leases, ledgers and an audit trail. The brief names SQL Server.

## Decision

One SQL Server database, EF Core 10, code-first migrations in `Infrastructure/Persistence/Migrations`. In docker-compose a one-shot `migrator` container (the API image run with the `migrate` argument) applies migrations and seeds before the API starts. The API itself never migrates on startup except when `Database:MigrateOnStartup` is set (local `dotnet run` and integration tests).

## Consequences

Several API replicas can start safely. Migrations are generated by `dotnet ef migrations add`; schema rules EF cannot express (the audit trigger) are added to the migration by hand.
